# Фронтенд підсистеми генерації звітів

STEM-проєкт «Звітня». **Клебанський Іван Михайлович, ІПЗ-31**.
Освітній компонент: «Розробник фронтенду програмних систем».

React-застосунок із каталогом і редактором шаблонів, живим переглядом, формуванням звітів та експортом. Бекенд не потрібен: тестові операції містяться в JSON, копії шаблонів — у localStorage.

## Запуск

Потрібні Node.js 22.12+ та npm. У корені проєкту:

```sh
npm ci
npm run dev
```

Відкрийте адресу Vite, зазвичай http://127.0.0.1:5173.

Демовхід: **demo@zvitnia.test / Demo2026!**. Кнопка «Заповнити демодані» заповнює форму. Це демонстрація клієнтської валідації й сеансу, а не справжня серверна автентифікація. Не вводьте особисті паролі.

```sh
npm test
npm run build
npm run preview
```

Перегляд збірки запускається окремою останньою командою.

## Сценарій роботи

1. Увійдіть, знайдіть шаблон пошуком і категорією та відкрийте його.
2. Натисніть «Редагувати». Змініть назву, заголовок, видимість колонок, їхній порядок стрілками, початковий період і відділ, формат CSV/PDF, таблицю/графік.
3. Перевірте живий результат. «Зберегти» створює власну копію базового шаблону або оновлює власний. «Зберегти як новий» завжди створює нову копію.
4. «Скинути» повертає стан на момент входу в редактор або останнього успішного збереження. Вихід із незбереженими змінами потребує підтвердження.
5. Перейдіть до перегляду шаблону, уточніть параметри запуску й натисніть «Сформувати звіт».
6. Перевірте підсумки та натисніть «Експорт CSV» або «Експорт PDF» залежно від шаблону.

У CSV експортуються всі записи й вибрані колонки в заданому порядку. Формат: UTF-8 BOM, `;`, CRLF, десяткова крапка. У режимі графіка CSV також містить детальні записи. PDF відкриває діалог друку: оберіть **«Зберегти як PDF»**. Друкується вся таблиця або графік із підсумками. Зміна параметрів блокує експорт до повторного формування; порожня вибірка не експортується.

Є світла/темна тема, мобільне компонування, повідомлення помилок, клавіатурні підписи й довідка «Як це працює». Порядок колонок змінюється стрілками.

## Збереження

- `zvitnia.templates.v2`: localStorage, JSON версії 2, до 100 власних шаблонів.
- `zvitnia.theme.v2`: localStorage, вибір теми; спочатку враховується системна тема.
- `zvitnia.demo-session.v2`: sessionStorage, email і строк завершення через 8 годин. Пароль не зберігається.

Копії доступні в тому самому браузері за тією самою адресою/портом. Очищення даних сайту видаляє їх. Пошкоджена бібліотека не перезаписується автоматично; помилка квоти не знищує чернетку. Збереження повторно читає бібліотеку, але не забезпечує транзакцій між одночасними вкладками. Чотири базові шаблони визначені у вихідному коді.

## Перевірки та межі реалізації

22 тести та виробнича збірка пройдені. Браузерна перевірка охопила вхід і помилки, пошук, формування, редактор, копію після перезавантаження, скидання, діалог незбережених змін, графік, теми, вихід та ширину 390 px. У консолі перевіреної вкладки помилок не виявлено. Вміст CSV перевіряють тести; UI передає файл браузеру. Виклик друку перевірено, остаточний браузерний PDF автоматично не зберігався.

Клієнтський демосеанс не захищає секретні дані. Немає сервера, синхронізації, ролей, реєстрації або історії звітів. Дані тестові. Пагінація не віртуалізує DOM. Google Fonts необов’язковий, є системний резерв. Випробування Chromium не замінює перевірку Firefox/Safari/Edge чи аудит WCAG. CSV обробляє небезпечні початкові символи формул, але повторне збереження в сторонніх програмах може змінити цей захист.

## Документація та подання

Записка містить потік користувача, стани кнопки `idle → loading → success/error`, стани редактора та User Guide за планом додатка. Перед поданням додайте фактичне посилання на власний Git-репозиторій у підрозділ 2.1. Код не публікувався автоматично.

Для повторної генерації документа потрібні Python, python-docx, Pillow і шрифти Times New Roman у Windows:

```sh
python docs/build_report.py
```

Після зміни тексту перевірте пагінацію й зміст у Word. `docs/render_with_word.ps1` створює внутрішній PDF для контролю верстки через встановлений Word; цей PDF не є експортом вебзастосунку.
